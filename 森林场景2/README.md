# 生命探索者 · 史前森林

这是可以直接部署到 GitHub Pages 的静态网页。仓库根目录的 `index.html` 是入口；`assets/` 是网页脚本，`models/` 是运行所需的八个 GLB。无需 Node.js、Blender 或构建命令。

## 发布

将本文件夹内容上传到 GitHub 仓库根目录，在仓库 Settings → Pages 中选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`。发布后打开 GitHub 给出的 Pages 地址，点击“开始探索”。首次进入需要下载约 37 MB 的模型。

本地预览需使用静态服务器，不能直接双击 `index.html`：

```bash
python3 -m http.server 8000
```

然后打开 `http://127.0.0.1:8000/`。

## 场景与操作

本版将树木从 451 棵增加到 1,353 棵，并加入用户提供的「高饱和度矮树」「树3」和灌木。WASD 移动、鼠标观察、Shift 加速、Space 跳跃。下方菜单切换步行、自由飞行和俯瞰；还可调整画质、时间、雾气及全屏。
